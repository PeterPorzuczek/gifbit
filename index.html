Where animations come from
How to get a key
  1. Go to developers.giphy.com and create an account.
  2. Click Create an App and choose API, not SDK.
  3. Enter any name and description, then copy the key here.

A free key allows 100 requests per hour. The page uses one request per keyword when it starts, then picks from what it has already loaded.

Separate with commas, up to 10. English words return the most results.

Animation type

Stickers have a transparent background, so your background shows through. “Both” uses two requests per keyword.

Content

Giphy PG-13 filter. Uncheck it to allow everything.

Your sets

You have no sets yet. Load animations from keywords, review them and click “Save as set”, or import a file.

A set works without a key and uses no Giphy requests. The JSON file holds links to the animations, so you can move it to another computer or send it to someone.

Animation picker
